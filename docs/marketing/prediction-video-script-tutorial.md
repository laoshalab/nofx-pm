在讲操作之前，先纠正一个常见误解：预测市场，和 crypto 合约【重读】不是一回事。

合约有杠杆、有强平；预测市场没有这些。你买入 YES 或 NO，【重读】最大亏损就是你下注的本金，不会爆仓。

**镜 08 · 1:08–1:22**

【画面：三分屏——市场列表 / edge 公式 / 流动性警告】

我把它总结成三个系统需求，请你记住。

第一，【重读】市场太多。crypto 标签下，短周期 up/down 市场不断滚动出现，靠肉眼盯盘不现实。

第二，【重读】定价是概率。举个例子：某个市场的 YES 价格是 0.55，意思就是市场隐含「发生」的概率大约是 55%。你要找的，是你主观认为的概率，和市场价格之间的差——这个差，就叫【重读】edge，优势边际。

第三，【重读】执行要严谨。neg-risk、流动性够不够、买卖价差 spread 大不大、距离结算还有多久——任何一环出错，AI 再聪明也白搭。
